# 验证与验收方案

> 本文档定义 FringeLab 的科学、算法和实验验证方法，**不是当前版本已通过所有测试的声明**。实际通过状态必须由可重复的命令输出、测试报告和原始数据支持，并在发布记录中填写。

## 1. 验证的核心原则

一个“看起来像衍射曲线”的界面并不足以证明测量正确。项目必须分层验证：

1. **物理公式层**：单缝、双缝、精确几何、单位和不确定度公式本身正确；
2. **数值算法层**：剖面提取、峰谷检测、宽度、回归和饱和检测在合成真值上正确；
3. **图像管线层**：旋转、背景、gamma、噪声、模糊、量化和饱和后仍按预期降级；
4. **端到端交互层**：从输入、ROI、标定到导出的完整流程可重现；
5. **真实相机层**：权限、能力探测、曝光稳定、分辨率与资源释放符合实际设备；
6. **真实光路层**：与已知波长/独立仪器、不同 \(L\) 和重新搭建的结果一致。

分层的目的是定位误差来源。例如，合成数据精度很高但真实实验偏差大，常说明问题在缝片公差、空间标定、近场条件或相机管线，而不是波长公式本身。

## 2. 能力边界与验收证据

| 能力 | 最低证据 | 证据不足时的处理 |
| --- | --- | --- |
| pixel 剖面 | 已知数组/二维图像的金标单测试 | 不发布剖面分析 |
| mm 位置 | 两点标定和独立第三点验证 | 只显示 pixel |
| 波长 nm | 物理金标 + 合成验收 + \(a/d/L\) 完整 | 禁用波长输出并列出缺失量 |
| 位置法在真实光路中的准确性 | 已知波长、不同 \(L\) 和独立重复 | 标为实验性，不声称指标 |
| 相对峰高 | 锁定状态、背景、饱和检查和响应线性验证 | 纵轴只标 DN/a.u. 且附警告 |
| 校正相对辐照度代理 | 上述 + 响应函数，可选有效平场 | 不使用“校正辐照度代理”名称 |
| 绝对 lux/W/m² | 当前整链路可溯源定标与不确定度预算 | **默认不支持，界面不显示** |

## 3. 物理和数值单元测试

### 3.1 基本数学

至少覆盖：

- \(\mathrm{sinc}(0)=1\) 使用极限或数值稳定实现，不产生 `NaN`；
- \(\sin[\arctan(x/L)]=x/\sqrt{L^2+x^2}\)；
- SI、mm、µm、nm 之间的单位换算；
- 正负坐标与左右级次的符号；
- 输入超出 \(|n\lambda/a|\le1\) 或 \(|m\lambda/d|\le1\) 时给出受控错误，不静默产生 `NaN`；
- 小角结果与精确几何结果的差值计算。

纯公式测试应接近浮点数值误差，不应用实验容差（例如 2%）来掩盖单位或公式错误。

### 3.2 单缝

测试：

- 暗纹满足 \(a\sin\theta_n=n\lambda\)；
- 第一暗纹的左右对称性；
- 中央主极大精确宽度
  \(W_0=2L\tan[\arcsin(\lambda/a)]\)；
- 小角宽度 \(2L\lambda/a\) 与精确结果的差异；
- 完整 \(\mathrm{sinc}^2\) 曲线在暗纹处为零（无背景理想模型）；
- 次极大不被错当作等间距。

### 3.3 双缝

测试：

- 理想干涉亮纹 \(d\sin\theta_m=m\lambda\)；
- 理想干涉暗纹 \(d\sin\theta_h=h\lambda\), \(h\in\mathbb Z+1/2\)；
- 有限缝宽模型为 \(\mathrm{sinc}^2\beta\cos^2\alpha\)；
- 包络暗纹与干涉亮纹重合时出现缺级；
- 缝宽 \(a\) 与中心距 \(d\) 不被交换；
- 不等照明/可见度模型在 \(0\le V\le1\) 的边界行为。

### 3.4 回归

使用无噪声和已知噪声的 \(q_i=c+br_i\) 金标数据测试：

- 斜率、截距、标准误差、\(R^2\) 和残差；
- 单缝 \(\lambda=ab\) 和双缝 \(\lambda=db\)；
- 带权回归中大不确定度点的权重降低；
- 左右对称半间距对中心偏移的抵消；
- 删除、新增、重新定级后结果可重计算且有审计记录；
- 错级/缺级数据不会被静默填补。

### 3.5 不确定度

测试：

- 小角双缝一阶传播与人工计算一致；
- 单缝将 \(d\) 正确替换为 \(a\)；
- 不确定度为零时 Monte Carlo 退化为确定性结果；
- 固定随机种子时 Monte Carlo 可重现；
- 共同标尺误差 \(k\) 在每次 Monte Carlo 中只整体抽样一次，而不是每个峰独立抽样；
- 正态标准不确定度和矩形公差的参数含义不混淆；
- 输出均值/中位数/标准不确定度/95% 区间完整。

方法学参考 [JCGM 100:2008](https://www.bipm.org/en/doi/10.59161/jcgm100-2008e) 和 [JCGM 101:2008](https://www.bipm.org/documents/20126/2071204/JCGM_101_2008_E.pdf)。

## 4. 图像分析单元测试

### 4.1 ROI 和剖面

用可手算的小型二维数组验证：

- 沿行、沿列平均与预期一致；
- 转置图像时横/纵剖面交换正确；
- 带状 ROI 旋转后的坐标和取样边界；
- ROI 超出图像、宽高为零或过小时受控报错；
- 分析用原始帧像素，不受 CSS 缩放影响；
- 背景相减使用浮点/有符号数值，不发生 `uint8` 下溢；
- 保留未平滑剖面，平滑副本不覆写原始数据。

### 4.2 峰、谷和宽度

使用高斯峰、拋物线峰、不对称峰、平顶峰和多峰数组验证：

- `distance`、`prominence`、`height`、`width` 和 plateau 筛选；
- 负曲线检测暗纹；
- 局部拋物线对亚像素峰位的恢复；
- FWHM 左右交点的线性插值；
- 扣除局部背景前后宽度定义不混淆；
- 饱和峰的峰高和 FWHM 被标记无效，而不伪造一个亚像素峰顶；
- 边界截断峰不被当作完整峰。

如实现参考 SciPy 语义，需用已知数组对照 [SciPy `find_peaks` 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html)，而不只比较直觉上的峰数。

### 4.3 饱和检测

构造：

- 单像素尖峰；
- 高端直方图堆积；
- 连续 3、10、50 pixel 平顶；
- 峰值低于 255 但经色调压缩形成的平台；
- 仅 R 饱和、G/B 未饱和的彩色帧；
- 高光周围的 blooming/光晕。

验证它们会触发正确的通道警告和结果降级。`>=250/255` 可是默认强剪切起点，但测试还必须覆盖“未达 250 的平顶”，以证明算法不只是查找 255。

## 5. 空间标定测试

### 5.1 两点标定

- 100 pixel = 10.00 mm 应得到 0.1000 mm/pixel；
- 交换两点顺序不改变正尺度；
- 两点重合时受控报错；
- 带非零不确定度的 \(D\) 和 \(P\) 传播正确；
- 使用独立第三点时残差正确报告；
- 分辨率改变后旧标定被标记不匹配，不静默继续使用。

### 5.2 四点单应性/畸变（如实现）

使用已知投影矩阵变换的矩形网格，验证：

- 四角经变换后返回正确毫米坐标；
- 中间检查点的重投影误差；
- 带噪声标定点的不确定度；
- 四点近共线或顺序错误时不生成看似有效的矩阵；
- 去畸变和 homography 的顺序一致，不重复修正。

若未实现这些功能，测试计划可保留为路线图，但不得在功能列表中标记为通过。

## 6. 标准合成验收数据

仿真器必须同时保留输入真值、理论一维剖面、二维原始帧和经图像管线后的剖面。所有含随机噪声的验收用例必须固定随机种子，并在 fixture 元数据中保存算法版本。

### 6.1 双缝基准 D1

输入：

| 参数 | 值 |
| --- | ---: |
| \(\lambda\) | 650 nm |
| \(d\) | 0.25 mm |
| \(a\) | 0.04 mm |
| \(L\) | 1.000 m |
| 空间比例 | 0.05 mm/pixel |
| 背景/噪声/gamma/饱和 | 无 |

精确几何真值（从中心起）：

| 干涉亮级 \(m\) | \(x_m\) (mm) | \(x_m\) (pixel) |
| ---: | ---: | ---: |
| 1 | 2.6000088 | 52.00018 |
| 2 | 5.2000703 | 104.00141 |
| 3 | 7.8002373 | 156.00475 |

单缝包络第一暗纹为 \(x\approx16.2521459\) mm（约 325.0429 pixel）。使用 \(A=(d+a)/2\) 的 Fresnel 数约 0.03235。

验收：

- 无噪声、无饱和时，波长相对误差 < 0.2%；
- 峰谷级次、包络位置和精确几何方向正确；
- 小角和精确结果分开显示/导出，不静默混用。

### 6.2 单缝基准 S1

输入：

| 参数 | 值 |
| --- | ---: |
| \(\lambda\) | 532 nm |
| \(a\) | 0.10 mm |
| \(L\) | 1.000 m |
| 空间比例 | 0.05 mm/pixel |
| 背景/噪声/gamma/饱和 | 无 |

精确暗纹真值：

| \(|n|\) | \(|x_n|\) (mm) | \(|x_n|\) (pixel) |
| ---: | ---: | ---: |
| 1 | 5.3200753 | 106.40151 |
| 2 | 10.6406023 | 212.81205 |
| 3 | 15.9620331 | 319.24066 |

中央主极大精确宽度 \(W_0\approx10.6401506\) mm，Fresnel 数约 0.004699。

验收：

- 无噪声、无饱和时，第一暗纹法、多级回归和完整 \(\mathrm{sinc}^2\) 拟合的波长相对误差各自 < 0.2%；
- 中央宽度是两侧第一暗纹间距，不与 FWHM 混淆；
- 单缝次极大不被当作等间干涉峰。

### 6.3 缺级基准 D2

选择 \(d/a=5\) 且其他条件使第 5 级干涉亮纹在第一单缝包络暗纹处。验证：

- 第 5 级亮峰在理想乘积模型中消失；
- 峰检测器不伪造该峰；
- 级次逻辑不把后续峰整体错移一级；
- 质量报告能说明包络缺级。

### 6.4 饱和基准 Q1

在 D1 和 S1 的理论图上增加增益并剪切中央峰，生成宽平顶。验收：

- 触发高优先级饱和警告；
- 峰高、FWHM 和强度模型拟合标记无效/降级；
- 不通过插值“恢复”峰顶；
- 如果侧峰/暗纹位置仍未受影响，允许输出明确标为“仅位置法”的波长；
- 若 blooming 使暗纹也偏移，则整个波长结果无效。

### 6.5 中等退化基准 N1

“中等噪声”不应只是文字标签，fixture 必须写出全部数值和随机种子。建议最小包含：

- 8-bit 量化；
- 固定 gamma/单调色调曲线；
- 已知标准差的加性读出噪声；
- 信号相关的光子噪声或其明确近似；
- 已知幅值的背景常数与线性梯度；
- 小幅固定图样噪声/speckle；
- 已知 \(\sigma\) 的模糊；
- 不导致剪切的峰值；
- 固定随机种子和帧数。

对预先冻结的 N1 数据集，位置法波长相对误差目标 < 2%。注意：不能在看到结果后不断改噪声参数直到通过；fixture 一旦作为发布门禁，参数改变必须有版本和理由。

### 6.6 几何退化基准 G1

逐项和组合添加：

- 图样旋转；
- 中心偏移；
- 屏面透视；
- 镜头径向畸变；
- ROI 轻微截断；
- 帧间平移。

当前版本已实现的矫正应恢复到预定容差；尚未实现的矫正必须触发可见的质量警告或在文档中限定适用范围，而不是将带透视的结果标为高可信。

## 7. 导入、导出和可复现性

每种实际实现的文件格式都要进行 round-trip 测试：

1. 导出实验会话；
2. 在全新应用状态中导入；
3. 重新计算；
4. 比较输入参数、ROI、标定、峰谷、波长、不确定度和 QC 标志。

测试至少覆盖：

- 小数精度和单位不丢失；
- `NaN`/`Infinity` 不被静默写成伪造数字；
- CSV 中中文、逗号和换行正确转义；
- JSON schema/版本号和向后兼容或受控迁移；
- 人工修改峰谷的审计记录保留；
- 导出数据中明确保存纵轴是 DN、a.u. 还是经哪一级校正；
- 缺失 \(a/d/L\) 的会话导入后不伪造波长；
- 引用的 calibration ID 存在、条件匹配，或明确报失效。

数值不变还不够：图表轴、单位、方法标签和警告也必须复现。

## 8. 端到端测试

至少使用 Playwright 或等价工具验证当前实现的以下流程：

- 首次进入页面，安全/科学边界可见；
- 仿真或示例数据的完整分析流程；
- 切换单缝/双缝后参数定义和公式更新；
- 选择/调整 ROI，清理旧的不匹配峰谷；
- 空间标定，在无标定时保持 pixel；
- 填入/清空 \(a\)、\(d\)、\(L\) 后波长计算正确启用/禁用；
- 人工增删/重新定级峰谷，结果和审计记录更新；
- 饱和数据的警告和位置法降级；
- 导出当前实现的 CSV/JSON/图表，再导入可复现；
- 中文/英文（若实现）和桌面/移动布局；
- 处理不完整文件、无效数字和超大图像时的受控错误。

摄像头权限在自动化中可用模拟 MediaStream 验证 UI 状态机，但这不取代真实浏览器/设备测试。

## 9. 真实相机验证

### 9.1 最小设备矩阵

建议至少覆盖：

- macOS + Safari/Chromium，内置摄像头；
- Windows + Chromium/Edge，常见 USB webcam；
- Android + Chrome，后置摄像头；
- iOS + Safari，后置摄像头；
- 一台支持部分手动控制的设备和一台不支持的设备。

实际矩阵应按项目目标用户的设备分布扩展。

### 9.2 每台设备的检查

1. HTTPS/localhost 下权限允许、拒绝和撤回；
2. 前/后/多摄像头选择；
3. 请求分辨率与实际 `getSettings()` 分辨率；
4. `getCapabilities()` 与控件显示一致；
5. `applyConstraints()` 后的实际 settings 与连续帧响应；
6. 手动曝光不支持时显示降级说明，不崩溃；
7. 镜头遮住/均匀场下的黑电平和帧间稳定性；
8. 饱和从哪一个通道先出现，警告是否正确；
9. 页面停止、路由切换或关闭后 MediaStreamTrack 释放；
10. 长时间运行的内存、CPU、帧率和温升。

W3C 规范定义了可约束的图像采集属性，但兼容性结论必须来自实际设备，见 [MediaStream Image Capture](https://www.w3.org/TR/image-capture/)。

## 10. 真实光路科学验证

### 10.1 参考真值

优先级：

1. 经校准光谱仪对同一激光器的同期测量；
2. 有校准证书和不确定度的激光波长标准；
3. 制造商标签值与容差；
4. 教材上的典型颜色数字只可作粗略合理性检查，不可作无不确定度的真值。

不要默认所有“红激光”都是 650 nm，或所有“绿激光”都是 532 nm。

### 10.2 实验设计

对每个待验证的单缝/双缝组合：

1. 独立确定 \(a\) 或 \(d\) 及不确定度；
2. 选择至少 3 个屏距 \(L\)，并确保主要条件处于可接受的 Fraunhofer 区；
3. 每个 \(L\) 下重复采集至少 3 组；
4. 至少进行 2 次完全重新搭建/对准；
5. 保存原图、背景、标定、相机 settings、峰谷和全部输入；
6. 在看到参考波长前冻结 ROI/峰检测/排除规则，或至少保留全部调整记录；
7. 同时计算快速小角法、多级精确回归和（数据质量许可时）完整模型拟合。

### 10.3 必须看的图，不只是一个平均误差

- 测得波长对 \(L\)；
- 测得波长对 Fresnel 数 \(N_F\)；
- 回归残差对级次；
- 左侧和右侧单独得到的波长；
- 小角法与精确几何法差异；
- 波长偏差对饱和比例/每周期像素数；
- 重复搭建的组间差异；
- 测量值与参考值的差异及合成不确定度。

如果波长随 \(L\) 有系统变化，需要检查近场模型、\(L\) 零点、空间标定和屏面透视；不应通过只报告所有 \(L\) 的总平均来隐藏趋势。

### 10.4 建议验收指标

下列是项目初期的工程目标，不是对所有相机/缝片/光路的通用保证：

- 在无噪声理论仿真中，波长误差 < 0.2%；
- 在冻结的中等退化仿真中，位置法误差 < 2%；
- 真实实验中，测量值与参考值的差异应与合成不确定度相容，或对不相容做出可重复的原因分析；
- 饱和、标定缺失、近场、ROI 截断和相机无法锁定时，结果必须按设计降级，“警告正确”本身也是验收目标。

在真实实验里设定固定的百分比精度前，应先根据缝片公差、标定和重复性建立误差预算。如果 \(d\) 的公差已是 3%，软件就不应宣称整个真实实验可以达到 0.2%。

## 11. 相对强度管线验证

当项目要超越位置测量，验证顺序应为：

1. **暗场**：测量偏置、读出噪声和帧间稳定；
2. **响应线性**：固定均匀场、扫描实际曝光时间，检查扣暗信号/曝光时间；
3. **饱和和有效范围**：确定从噪声底到高光压缩/剪切前的范围；
4. **平场**：在均匀场下检查校正前后空间非均匀性；
5. **帧间稳定**：固定光场下记录均值和直方图随时间的变化；
6. **多曝光一致性**（如实现）：在重叠动态范围内，线性化并除以曝光时间后的信号一致。

SPECTACLE 提供了消费级相机光谱/辐射定标的系统方法参考 [Burggraaff et al., 2019](https://doi.org/10.1364/OE.27.019075)；EMVA 1288 提供线性图像传感器的响应、噪声、暗电流、饱和和非均匀性框架 [EMVA 1288 Release 4.0](https://www.emva.org/wp-content/uploads/EMVA1288Linear_4.0Release.pdf)。后 ISP webcam 如不满足这些前提，测试结论应是“不适用/降级”，而不是为了通过而忽略非线性。

## 12. 不确定度验证和覆盖性

### 12.1 分量与 Monte Carlo 交叉检查

对近似线性、输入近似正态的小角公式，解析一阶传播与 Monte Carlo 应在采样误差内一致。对精确几何、矩形公差或非对称输出，允许两者不同，但必须能用模型非线性和分布假设解释。

### 12.2 合成覆盖性

生成大量已知真值的输入，按声称的 95% 覆盖区间计算包含真值的频率。覆盖率明显偏低可能说明：

- 峰位不确定度被低估；
- 共同标定误差的相关性处理错误；
- 排除了模型偏差；
- 拟合协方差在非线性/错模型情况下过于乐观；
- 通过数据选择形成了幸存者偏差。

### 12.3 真实实验的一致性

对有参考波长 \(\lambda_{\rm ref}\) 和标准不确定度 \(u_{\rm ref}\) 的实验，可使用归一化差异作诊断：

\[
E_n=
\frac{|\lambda_{\rm meas}-\lambda_{\rm ref}|}
{\sqrt{U_{\rm meas}^2+U_{\rm ref}^2}},
\]

其中 \(U\) 必须使用相同覆盖概率的扩展不确定度。\(E_n\le1\) 可作为一致性诊断，但它不能替代残差、趋势和数据质量检查；人为放大不确定度使 \(E_n\) 通过也不是有效验证。

## 13. 性能、稳定性和隐私

### 13.1 性能

在目标桌面和移动设备上记录：

- 预览 FPS 和分析刷新率；
- 单次剖面、峰检测、回归和 Monte Carlo 的耗时；
- 30 分钟运行的内存趋势；
- 切换输入/停止摄像头后的资源释放；
- 主线程长任务、界面卡顿和移动设备发热；
- 超大图像或高帧率输入的降采样/背压行为。

分析可以低于预览帧率，但不应在用户不知情时改变原始分析尺度或丢弃用于波长的关键帧。

### 13.2 本地处理与隐私

通过浏览器开发者工具和网络测试验证：

- 摄像头视频不上传；
- 实验图像/剖面不在用户未操作时发送到第三方；
- 不加载未声明的跟踪器；
- 用户停止后摄像头指示灯/track 关闭；
- 本地会话清除功能实际删除相应数据；
- 导出只在用户明确操作后发生。

## 本轮处理

1. 原始过曝不是显示亮度问题。保留源像素与原始 RGB 饱和检测，不对剪切峰高或 FWHM 进行虚构恢复。新增近竖直彩色条纹的建议选区，排除尺子刻线与手指；其他方向仍需手动调整。已验证同向且未饱和的通道可辅助定位，但不等于绝对光强定标。
2. 参数填入、尺标候选、已应用标定分别显示；候选优先显示“候选未应用”，不会被旧的“已失效”状态盖住。检测到已知尺标进入 ROI 时，先引导调整选区，再计算。
3. 实测双缝界面直接提供可选的 a 输入。空白表示未知；填写正数即启用，不再要求额外勾选。d 是两个缝的中心距，a 是单个缝的宽度，不能互相替代。参数/尺标未准备好时不输出远场数值。
4. 默认教学模式：应用参数与尺标 → 在画面点选两个亮纹中心 → 数间隔 N → 输入 Δx、λ → 分层提示/计算核对 → 自主揭示。6 条亮纹包含 5 个间隔。遮蔽涵盖自动间距、波长、特征位置、模型曲线和导出；这是教学交互，不是安全权限控制。分析模式同样需主动点击计算，切换模式不会生成结果。JSON 保留用户选点及其计算，并注明自动吸附辅助定位。
5. 中文正文与输入框采用 16px；辅助说明以 14–15px 为主，标题 18px，数值 24–34px。专业设置、质量详情默认折叠，保留主流程与下一步提示。中文优先使用系统中文字体，拉丁字母使用既有 Geist，数据保持等宽数字。

## 验证记录

- 55 项单元测试和 2 项服务端渲染测试通过，新增亮纹吸附、旋转坐标同步、安全计算器及页面结构测试；TypeScript、ESLint、Next 生产构建及既有 Vinext 构建通过。
- HEIC 原图 4032×3024 实测：建议选区 636×24 显示像素，五点尺标，d=0.25 mm、L=5.510 m、a=0.04 mm。自动回归约 Δx=14.475 mm、λ=656.7 nm，红通道原始饱和约 22.1%，故仍标记暂估；不同 ROI 的差异不应误当准确度认证。
- 浏览器实测了点选、间隔计数、分层提示、输入答案核对、揭示/重新遮蔽、分析模式和 JSON 导出。计算核对容差 2% 只用于学习反馈，不是仪器误差规范。
- 重置 ROI 包含尺子后会阻止物理输出并显示选区引导，重新建议选区可解除。
- 390px 手机视窗无横向溢出，正文/输入框实际计算字号 16px，浏览器无运行错误。
- 自动尺标及 OCR 仍需人工核对单位与刻线，不能把识别一致性当成测量精度。未增加图片上传后端，也未完成实体摄像头的现场曝光复测。

## 亮纹联动与界面精简（最新本地修订）

- 用户点击附近亮纹后，以原图分析得到的局部峰中心磁吸；不是全图最大亮度。将原图轴坐标换算为显示坐标，A/B 同时标记于光学画面和剖面的圈、竖线。ROI、方向、平滑、通道或输入源变化后旧选点失效，避免错配。
- 对饱和峰沿用颜色对比辅助的中心暂估，不虚构唯一最大像素、不恢复峰高。自动吸附与自动回归使用同一定位数据，因此不是两套独立测量验证。
- 右侧删除参考偏差、大号三卡布局；主动点击计算或教学揭示后显示两个紧凑数值、触发时间和方法。参数/尺标/选区变化后需重新计算。摄像头计算与点选冻结分析帧；恢复采集时清除旧计算。
- 删除光学画面下方三张输入状态卡，诊断仍可在质量详情查看。摄像头选择、重启、设置锁定、冻结、断开集中到光学画面内部，专业设置不再重复。
- 计算器按钮位于“一起测出条纹间距”标题右侧，点击在练习面板右边打开非模态浮窗，不占用分析面板的布局空间。可关闭或按 Esc 收起，保留算式，关闭后焦点返回按钮；小屏幕固定在屏幕内。支持四则、括号、乘方和科学计数；纯算式解析，无 eval，不读取教学答案、不代填输入。
- 数值字段保留输入草稿，修复清空后粘贴小数被旧数值拼接的问题。
- 4032×3024 的 IMG_6816.HEIC 实测五点尺标：故意偏离亮峰点选后仍吸附；A/B 剖面索引约 529.349、2980.600，两端跨度约 86.947 mm；N=6 时约 657.5 nm，自动回归约 656.7 nm。结果仍为过曝暂估，这些一致性不构成准确度认证。
- 已浏览器核验：未点击不显示数值、揭示触发、修改 L 清除旧结果、重新计算、计算器除零提示、JSON 元数据与峰位一致；390px 视窗无横向溢出。
- 使用 Canvas 测试视频流与两个测试设备条目核验摄像头输入下拉框的作用域、切换后请求指定 deviceId、冻结/断开交互；未访问真实摄像头，未进行现场硬件曝光复测。

### 亮纹还是暗纹：文献与设计判断

双缝建设性干涉条件为 d sinθ=mλ，破坏性干涉为 d sinθ=(m+1/2)λ。由此在小角近似下，两类各自相邻条纹均有 Δx≈λL/d；不能把亮—暗间隔当作完整周期。这支持两种测法，并不说明亮纹在所有照片中更精确。本项目选择亮纹是教学交互的设计判断；饱和时可用清晰暗纹交叉核验，但应排除背景、缺级与衍射包络干扰。单缝则使用 a sinθ=mλ 的暗纹位置，不能简单应用等间距亮峰法。

- [OpenStax：双缝亮纹与暗纹条件](https://openstax.org/books/university-physics-volume-3/pages/3-2-mathematics-of-interference)
- [OpenStax：单缝暗纹条件](https://openstax.org/books/university-physics-volume-3/pages/4-1-single-slit-diffraction)

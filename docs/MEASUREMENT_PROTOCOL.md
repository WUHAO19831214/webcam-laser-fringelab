# 实验测量操作规程

> 适用范围：使用低功率教学激光器、单缝或双缝、漫反射光屏和 webcam/手机摄像头，测量条纹位置、相对相机响应和激光波长。本规程不将普通摄像头当作未经定标的 lux 计。

## 0. 先做安全检查

激光可以在不立即疼痛的情况下造成严重眼损伤。美国 FDA 指出，直射眼睛的激光能量可造成永久损伤，镜子、抛光金属等的镜面反射同样危险；功率标注不明的网购激光笔不应默认为安全 [FDA 激光安全信息](https://www.fda.gov/radiation-emitting-products/alerts-and-notices/illuminating-facts-about-laser-pointers)。

实验开始前必须确认：

- 只让相机和人眼观察光屏的漫反射，不沿激光传播方向观察；
- 激光器、缝片和光屏用稳固支架固定；
- 光屏是有效的光束终止端，没有透过光屏或越过屏幕的直射束；
- 光路附近移除镜子、玻璃、手表、抛光金属等镜面反射物；
- 调整光路时使用最低可行功率，不把头部放入光路高度；
- 激光器有清楚的类别、波长和输出标识，并遵守所在地法规及学校/实验室规程；
- 儿童和未经培训者不单独操作；
- 软件的“曝光安全”或“未饱和”只描述相机数据，**不代表人眼安全**。

## 1. 所需器材和记录表

### 1.1 基本器材

- 波长大致已知、类别和功率标注清楚的低功率教学激光器；
- 单缝片或双缝片，有可信的缝宽 \(a\) 或双缝中心距 \(d\) 及公差；
- 稳固的光学支架或定位工装；
- 平整、无光泽、纹理尽量均匀的白色或中性灰光屏；
- 刻度尺或已知长度标志，用于 mm/pixel 空间标定；
- 卷尺/钢尺，用于测量缝平面到光屏平面的 \(L\)；
- 可固定的 USB webcam、电脑内置摄像头或手机后置摄像头；
- 可选：合规的中性密度（ND）滤光片。

### 1.2 每次测量必须记录

- 日期、操作者和实验地点；
- 激光器型号、标称波长及容差；
- 缝片型号，\(a\) 或 \(d\) 的数值、单位和不确定度；
- \(L\) 及其不确定度；
- 相机型号、视频分辨率、镜头/数字变焦状态；
- 实际可读取的曝光、ISO/增益、白平衡和对焦状态；
- 空间标定方法和标志真实长度；
- 所用颜色通道、ROI、背景帧和分析参数；
- 饱和、Fresnel 数、残差和其他质量警告。

## 2. 搭建光路

### 2.1 位置关系

按以下顺序摆放：

```text
激光器 → 单缝/双缝 → 光屏
                              ↖ 摄像头只看光屏漫反射
```

关键几何要求：

1. 激光近似垂直照射缝片；
2. 光屏尽量与中心光轴垂直；
3. 相机尽量正对光屏，同时稍微偏离直射反射方向，避免镜面热点；
4. 标定尺与衍射图样位于**同一光屏平面**；
5. 图样完整落入画面，两侧至少保留一定背景区；
6. 不使用数字变焦；任何变焦、分辨率或相机位置改变后都重做空间标定。

### 2.2 距离 \(L\)

\(L\) 是缝片平面到光屏平面的距离。测量时应：

- 从缝片的实际孔径平面起算，不是支架边缘；
- 测到光屏的成像平面，不是墙体背面；
- 至少重复测量 3 次，记录分辨力、零位和对准带来的不确定度；
- 不得用相机到屏面的距离代替。

### 2.3 远场检查

在采集前使用标称波长估算

\[
N_F=\frac{A^2}{\lambda L},
\]

其中单缝取 \(A=a/2\)，双缝可取 \(A\approx(d+a)/2\)。当 \(N_F\) 不足够小时，优先增大 \(L\)。测得波长后再用测量值重算一次。阈值只是工程诊断，详见 [科学依据](./SCIENTIFIC_BASIS.md#7-fraunhofer-远场条件)。

## 3. 连接相机并准备图像

### 3.1 选择输入

使用浏览器摄像头时，页面需在 `localhost` 或 HTTPS 安全上下文中运行。如果摄像头权限被拒绝，可先使用上传图像或项目中实际提供的仿真模式熟悉流程。

对严格实验，优先使用：

- 无数字缩放的原始视场；
- 相机稳定支架；
- 实际能锁定曝光/增益/白平衡/对焦的设备；
- 在光强和存储许可时能提供较高分辨率的设备。

### 3.2 对焦与几何

1. 用光屏上的刻度和图样边缘对焦；
2. 对焦完成后锁定，或至少保证自动对焦不再周期性搜索；
3. 使条纹尽量水平或垂直；如果无法完全对齐，ROI 必须跟随条纹方向；
4. 不让 ROI 跨越光屏折痕、污点、印刷字样或标尺本身。

### 3.3 曝光和通道

1. 在相机实际支持时，将曝光设为手动，降低 ISO/增益；
2. 关闭自动 HDR、美颜、夜景、自动对比度和人像增强，若设备允许；
3. 根据 R/G/B 的饱和比例、平顶和信噪比选择通道；
4. 调整曝光，使最强的有用峰明显低于饱和码值；工程上可以把约 70%–80% 满量程作为起点，但以设备实际直方图为准；
5. 如果最低曝光仍饱和，降低激光功率或正确使用 ND 滤光片；
6. 设置后等待数秒使自动算法稳定，再检查实际 `getSettings()` 或连续帧统计。

当设备无法手动锁定时，仍可进行条纹位置和波长实验，但要把数据等级标为“位置测量”；不应比较不同时刻的绝对峰高。

## 4. 空间标定

标定必须使用图像的原始像素坐标，不能使用 CSS 缩放后在屏幕上的显示像素。

### 4.1 两点标定

1. 把有可读刻度的尺放在图样同一平面；
2. 选择间距尽可能长、边缘清晰的两个标志；
3. 记录真实间距 \(D_{\rm mm}\) 及不确定度；
4. 在图像中标注两点，得到像素距离 \(D_{\rm px}\)；
5. 计算 \(k=D_{\rm mm}/D_{\rm px}\)，单位 mm/pixel；
6. 在第三个已知位置上验证转换误差。

两点标定只适合相机近似正对屏幕、ROI 较小、镜头畸变可忽略的情况。四点平面矫正和镜头畸变标定如未在当前版本中提供，应视为路线图，不能在报告中假定已经校正。详见 [标定指南](./CALIBRATION.md)。

## 5. 采集背景和实验帧

### 5.1 暗场（可选但推荐）

保持曝光、增益、分辨率、白平衡和对焦不变，完全遮住镜头或使传感器处于等价遮光条件，采集多帧平均。注意：单纯关闭激光不是暗场，因为环境光仍在。

### 5.2 环境基线

1. 关闭或完全遮断激光；
2. 保持实验室照明、光屏、相机位置与相机设置不变；
3. 采集一组帧，推荐从 16–32 帧起步；
4. 检查基线在采集期间是否漂移。

### 5.3 实验帧

1. 重新打开激光，不移动任何器材；
2. 等待激光器输出和相机处理稳定；
3. 检查图样未移出 ROI、主峰未饱和、相机设置未改变；
4. 采集多帧，并保留帧间总信号、峰位和峰高的变异信息；
5. 若图样漂移，先检查支架和自动对焦，不要用过度平滑隐藏问题。

暗场、环境基线和实验帧必须来自相同的相机状态。如果曝光/增益发生变化，应重新采集背景。

## 6. 选择 ROI 和生成剖面

1. 用带状 ROI 覆盖完整图样，并保留左右或上下背景；
2. ROI 长轴指向强度变化方向，ROI 的宽度方向与条纹平行；
3. 轻微旋转 ROI，使条纹在平均方向上不被拖宽；
4. 沿条纹平行方向对多行/多列求均值或 trimmed mean；
5. 保留原始剖面，轻度平滑只用于峰谷检测；
6. 平滑窗应明显小于条纹周期，可从不超过周期的 1/5 开始；
7. 检查曲线中的峰、谷与原图中亮、暗纹是否一一对应。

如果边缘条纹被 ROI 截断，不要把截断边缘当作峰或暗纹。

## 7. 选择波长计算方法

### 7.1 双缝：推荐顺序

1. **多级精确回归**：对多个亮纹或暗纹的 \(q_i=\sin\theta_i\) 对级次回归，用 \(\lambda=db\) 得到波长；
2. **完整模型拟合**：在曲线未饱和且相机响应足够稳定时，拟合 \(\mathrm{sinc}^2\times\cos^2\) 模型；
3. **相邻峰平均间距**：只用于中央附近、小角快速结果，\(\lambda\approx d\Delta x/L\)。

如果看到包络中某些干涉峰消失，先考虑缺级，不要简单判为检测失败。

### 7.2 单缝：推荐顺序

1. **多级暗纹精确回归**：用 \(q_n=c+bn\)，\(\lambda=ab\)；
2. **完整 \(\mathrm{sinc}^2\) 模型拟合**：仅在峰未饱和、背景可建模时使用；
3. **中央主极大宽度**：用两侧第一暗纹的距离 \(W_0\)，小角下 \(\lambda\approx aW_0/(2L)\)。

单缝次亮峰不是严格等间距的，不要照搬双缝的相邻峰公式。

### 7.3 必要的人工复核

自动检测后必须对照原图复核：

- 中心 \(x_0\) 是否合理；
- 峰/谷是否与亮/暗纹对应；
- 级次是否在中心两侧连续；
- 是否存在缺级；
- 是否把屏幕污点、speckle 尖峰或 ROI 边界当成条纹；
- 饱和峰是否已被标记为无效峰高/FWHM。

人工修改要保留记录，不应静默改动后只导出最终数字。

## 8. 结果质量门槛

下列阈值是建议的教学/工程诊断起点，不是通用计量标准。最终应结合设备验证设定。

### 可进入波长分析

- 空间标定有效，或明确使用原始 pixel 但不输出 nm；
- \(a\) 或 \(d\) 与 \(L\) 已填写且单位正确；
- 图样未被 ROI 严重截断；
- 有足够的峰/谷用于所选方法；
- 至少中央附近的有效条纹有足够像素采样；约 6–10 pixel/周期是可用的起点，更多像素更利于亚像素定位；
- 回归残差无明显系统弯曲或级次错配。

### 只能降级为位置法

- 无法锁定自动曝光/白平衡；
- 响应曲线未标定；
- 轻度饱和只影响峰顶，但可用暗纹和位置仍充足；
- 只有后 ISP 视频帧，无 RAW/线性化信息；
- 平场不可用，但局部位置仍清晰。

此时可报告波长和条纹位置，但不把峰高、可见度和 FWHM 当作已校正的物理强度量。

### 应停止并重新采集

- 直射激光可能进入人眼或相机；
- 大面积饱和或 blooming 使暗纹位置也不可信；
- 背景与实验帧使用了不同曝光/增益；
- 空间标定尺不在光屏平面，或变焦后未重标；
- 图样被 ROI 截断到无法定级；
- \(a\)/\(d\)/\(L\) 的定义或单位不清楚；
- \(N_F\) 较大而仍准备套用简单 Fraunhofer 模型；
- 帧间峰位大幅漂移，且无法解释或配准。

## 9. 重复测量与误差评估

一组“多帧平均”并不等于独立重复实验。建议至少完成：

1. **同一搭建下的重复采集**：重复采集 3–5 组，估计图像噪声和短期漂移；
2. **重新定位 ROI 的复现**：独立重选 ROI，检查分析者选择的影响；
3. **改变 \(L\)**：在可行的两个或以上屏距重做测量，波长应在不确定度内一致；
4. **重新搭建**：在高要求实验中至少完整拆装/对准后重做一次，这才能包含搭建复现性。

结果中同时报告：

- 平均波长；
- 组内重复性；
- 缝尺寸、\(L\) 和空间标定导致的系统项；
- 拟合或 Monte Carlo 得到的标准不确定度/95% 区间；
- 与激光器标签或独立光谱仪的偏差，但不把标签值当作无不确定度的真值。

## 10. 实验报告的最小内容

一份可复核的报告应至少包含：

1. 实验类型：单缝或双缝；
2. 光路图和安全措施；
3. \(a\) 或 \(d\)、\(L\)、空间标定及各自不确定度；
4. 原始图像或带 ROI 标记图；
5. 相机、分辨率、曝光/增益状态和分析通道；
6. 原始剖面、背景修正剖面和峰/谷标记；
7. 所选物理方法、公式和级次表；
8. 回归残差、Fresnel 数、小角近似偏差和饱和状态；
9. 波长结果、不确定度、有效数字和质量等级；
10. 所有人工修改、排除点和已知限制。

纵轴应标“相对光强（相机响应，a.u.）”或“DN”，除非有完整的绝对辐射定标链。

## 11. 常见问题排查

| 现象 | 可能原因 | 优先处理 |
| --- | --- | --- |
| 峰顶是平的 | 主通道饱和/ISP 截断 | 降曝光、降增益、降功率或用 ND；不插值恢复峰顶 |
| 曲线整体上下漂移 | AE/AWB 未锁、激光预热不足 | 锁定或等待稳定；不支持锁定时降级为位置法 |
| 峰很毛糙 | speckle、屏幕纹理、读出噪声 | 用哑光屏，加宽带状 ROI，多帧配准平均 |
| 条纹被拖宽 | ROI 方向与条纹不平行、失焦 | 旋转 ROI，重新对焦并锁定 |
| 左右不对称 | 光路倾斜、高斯光束偏心、屏幕透视 | 重新对准，保留回归截距，检查四点校正需求 |
| 波长经常偏高/偏低 | \(a/d/L\) 定义错、标定不同平面、近场 | 核对中心距与缝宽，重标 mm/pixel，计算 \(N_F\)，改变 \(L\) 复核 |
| 某些双缝亮峰消失 | 包络缺级或曝光不足 | 对照 \(a\) 与 \(d\) 的包络模型，不要自动补峰 |
| 换分辨率后结果变化 | mm/pixel 已失效 | 每次换分辨率/变焦/位置后重标 |

## 12. 实验结束

1. 先关闭激光器；
2. 再停止摄像头采集；
3. 导出必要的原始图像、剖面数据、峰谷表、参数和质量报告；
4. 保留未修改原始数据和分析版本，不只保留最终一个波长数字；
5. 记录异常、人工处理和下次需改进的光路条件。

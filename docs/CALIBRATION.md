# 标定指南

> 目标：把“图上有一些亮暗条纹”变成具有明确坐标、明确数据等级和可追溯元数据的测量。本文区分空间标定、背景/相对响应校正和绝对辐射定标。当前软件是否提供某个向导或算法，以 README 和界面为准；未提供的高级校正不得在报告中声称已完成。

## 1. 标定分层

| 层级 | 所需标定 | 允许的输出 | 不允许的声称 |
| --- | --- | --- | --- |
| A. 位置测量 | mm/pixel 或平面几何；\(a\)/\(d\)/\(L\) | 条纹位置、间距、波长；DN/a.u. 剖面 | 绝对峰高、lux、W/m² |
| B. 校正相对响应 | A + 固定曝光/增益/白平衡，背景，响应线性化，可选平场 | 在指定条件下的校正相对辐照度代理量（a.u.） | 跨设备/设置直接比较，绝对 lux/W/m² |
| C. 绝对辐射测量 | B + 波长相关、几何相关、可溯源的辐射定标 | 定标边界内的辐亮度或辐照度估计 | 本项目默认不支持；不得仅靠 RGB 换算 |

绝大多数教学波长实验只需 A 级。B 级用于比较同一搭建下的峰高、包络和可见度。C 级是独立的计量学项目，属于高级路线图。

## 2. 空间标定

### 2.1 基本原则

相机输出的条纹位置为 pixel。要得到 mm 和波长，必须知道光屏平面上真实距离与原始图像像素距离的关系。

标定物必须：

- 与衍射图样位于同一平面；
- 与强度剖面的测量方向一致，或者通过平面单应性明确转换；
- 尽量跨越长距离，降低点选择误差的相对影响；
- 不与屏面有可见的前后视差；
- 在不饱和、对焦清晰的图像中可重复定位。

标定必须基于相机输出帧的**原始尺寸**。界面上的 CSS 缩放、浏览器缩放和高 DPI 屏幕像素都不是分析像素。

### 2.2 两点标定

设两个标定点在光屏上的真实间距为 \(D\) mm，在原始图像上的像素距离为 \(P\) pixel，则

\[
k=\frac{D}{P}\quad\text{mm/pixel}.
\]

若剖面中某点的像素坐标为 \(p\)，中心为 \(p_0\)，则局部线性假设下

\[
x-x_0=k(p-p_0).
\]

若 \(D\) 与 \(P\) 独立，一阶近似下

\[
\left(\frac{u_k}{k}\right)^2
=
\left(\frac{u_D}{D}\right)^2
+
\left(\frac{u_P}{P}\right)^2.
\]

\(u_P\) 不应只设成固定的“0.5 pixel”；更好的方法是让同一人多次标注或多人独立标注，从重复性估计。尺本身的校准/制造公差、线宽、对焦和透视应计入 \(u_D\) 或额外系统项。

### 2.3 两点标定的局限

单一 \(k\) 只在下列条件下近似有效：

- 相机光轴近似垂直光屏；
- ROI 在画面中央且不太宽；
- 镜头畸变在所用视场内可忽略；
- 标定线段与剖面同向且空间位置接近。

只有一个水平 mm/pixel 时，不能默认它也等于画面其他位置或垂直方向的 mm/pixel。验证时应在不参与拟合的第三个尺刻处检查误差。

### 2.4 四点平面标定（高级路线图）

对平面光屏，可在屏上放置真实宽高已知的矩形标定板，标注四角，估计 3×3 单应矩阵 \(H\)：

\[
\rho
\begin{bmatrix}X\\Y\\1\end{bmatrix}
=H
\begin{bmatrix}u\\v\\1\end{bmatrix}.
\]

其中 \((u,v)\) 是图像坐标，\((X,Y)\) 是光屏毫米坐标，\(\rho\) 是齐次比例。单应性可修正平面透视，但不能自动修正镜头径向畸变。验证时应使用超过 4 个点并报告重投影误差。平面单应性的背景可参考 [OpenCV homography 教程](https://docs.opencv.org/master/d9/dab/tutorial_homography.html)。

当前版本如未提供单应校正，实验应尽量正对光屏并缩小 ROI，而不是用手工拉伸图像代替可复现的标定。

### 2.5 镜头畸变（高级路线图）

广角手机镜头或 ROI 靠近画面边缘时，径向畸变可使像素尺度随位置改变。标准做法是使用多个姿态的棋盘格/圆点板估计内参和径向/切向畸变，然后先去畸变、再做平面单应校正。可参考 [OpenCV Camera Calibration](https://docs.opencv.org/master/d4/d94/tutorial_camera_calibration.html)。

畸变标定与下列项绑定：

- 相机和镜头；
- 焦距/光学变焦；
- 对焦距离（某些镜头可能变化）；
- 采集分辨率、裁切和防抖状态。

## 3. 实验尺寸标定

### 3.1 缝宽 \(a\) 和双缝中心距 \(d\)

波长与 \(a\) 或 \(d\) 成比例，所以缝片公差经常是误差预算中的主导项。

- \(a\)：每条透光缝的宽度；
- \(d\)：双缝两条缝的中心到中心距离；
- 边缘空隙 \(g\) 如果已知，对对称等宽缝有 \(d=g+a\)，但不应在缝宽不明时默认这一换算。

优先级为：制造商校准证书/可溯源显微测量 > 带分辨率和标定的显微镜测量 > 标称值与制造公差。不要通过同一张未知波长的衍射图同时拟合 \(a/d\) 和 \(\lambda\)，因为绝对尺度不可辨识。

### 3.2 屏距 \(L\)

\(L\) 从缝的孔径平面测到光屏成像平面，而不是激光器、支架边缘或相机。对不完全平行的缝平面和屏面，单一 \(L\) 不足以表示所有位置；应先调整平行/垂直关系。

重复测量时记录：

- 尺的分度和零位；
- 缝平面和屏面的定位宽度；
- 尺是否与光轴平行；
- 多次读数的标准差。

## 4. 相机状态标定

### 4.1 能力探测不等于能力实现

[W3C MediaStream Image Capture](https://www.w3.org/TR/image-capture/) 定义了曝光模式、曝光时间、ISO、白平衡、对焦和变焦等约束属性。实验软件应按以下顺序工作：

1. `getSupportedConstraints()` 只说明浏览器认识某个约束名；
2. `track.getCapabilities()` 才描述当前设备/轨道可用范围；
3. `applyConstraints()` 请求修改；
4. 修改后使用 `getSettings()` 复查实际值；
5. 通过连续帧均值/直方图验证设置是否稳定。

对某些 webcam，浏览器会忽略或量化某些请求。因此每个校正数据集都应保存实际 settings，而不只保存 UI 滑块值。

### 4.2 必须保持固定的条件

对 B 级相对响应测量，下列条件变化后校正失效：

- 曝光时间、帧率或电子快门模式；
- 模拟/数字增益、ISO；
- 白平衡增益、色温、色彩模式；
- gamma、HDR、夜景、局部对比度、降噪和锐化；
- 分辨率、像素合并、裁剪和数字缩放；
- 镜头、焦距、光圈和对焦；
- 视频编码路径或手机摄影模式。

当上述项无法锁定或读取时，不要试图将多次拍摄的峰高当作相同量纲的精确数据；将任务降级为 A 级位置测量。

## 5. 暗场与环境背景

### 5.1 定义

在线性化域中，可把激光打开的测量记为

\[
M=D+B+S,
\]

其中 \(D\) 是偏置/暗信号，\(B\) 是环境光与非目标散射的信号，\(S\) 是激光衍射图样的目标信号。激光关闭、其他条件不变时记录

\[
M_{\rm off}=D+B.
\]

因此

\[
S=M-M_{\rm off}.
\]

如果已直接减去同设置的 `laser off` 背景，暗信号已在差分中抵消，不应再将 \(D\) 从结果里减第二次。独立暗场仍然有用，因为它能用于估计黑电平、读出噪声、坏点和平场分母。

### 5.2 采集方法

暗场：

1. 完全遮光，不只是关闭激光；
2. 保持与实验帧相同的曝光、增益、分辨率和处理链；
3. 采集多帧，推荐 16–32 帧作为起点；
4. 保留均值图和标准差图/统计，而不只保留单一全局均值。

环境背景：

1. 激光关闭；
2. 光屏和实验室照明保持实验状态；
3. 不移动相机、ROI 或光屏；
4. 与实验帧相邻采集，减少日光/室内照明漂移。

背景相减应在浮点或有符号数组中进行。噪声可以产生轻微负值，不应在中间步骤使用 `uint8` 下溢或把所有负值立即截为零，因为这会对低信号产生正偏置。

## 6. 响应线性和相机响应函数

### 6.1 为什么要线性化

如果数字码值与到达传感器的曝光量成线性，则背景相减、平场除法、峰高比较和多曝光融合都有清楚物理意义。但浏览器视频帧通常经过色调曲线、白平衡、降噪、锐化和压缩。

SPECTACLE 的消费相机实验显示，RAW 通常比 JPEG 更线性，不同相机的偏置、ISO/增益、平场和光谱响应差别很大 [Burggraaff et al., 2019](https://doi.org/10.1364/OE.27.019075)。[EMVA 1288](https://www.emva.org/wp-content/uploads/EMVA1288Linear_4.0Release.pdf) 为线性图像传感器提供了响应、噪声、非均匀性与饱和的标准化表达。这两者可作为高级校正的方法论参考，但消费级后 ISP 视频不能因此自动声称符合 EMVA 1288。

### 6.2 曝光扫描法（高级路线图）

在均匀、稳定、未饱和的光场下：

1. 锁定增益/ISO、白平衡、对焦、分辨率和所有可控 ISP 选项；
2. 选择至少 8–12 档实际曝光时间 \(t_j\)，覆盖噪声底到饱和前的范围；
3. 每档采集多帧暗场和均匀场；
4. 用中心均匀 ROI 计算均值和方差；
5. 使用实际 `getSettings()` 中的曝光时间，不只使用请求值；
6. 检查扣暗后信号是否与 \(t_j\) 成比例；
7. 估计黑端、线性区、转折区和饱和区；
8. 如需响应函数，拟合严格单调的逆函数，保留残差和不确定度。

理想线性区中，

\[
\frac{DN(t)-D(t)}{t}
\]

应在不确定度内保持常数。如果相机在改变曝光的同时暗中改变了增益、白平衡、局部色调或帧率，此校准无效。

### 6.3 inverse-sRGB 的地位

对已知符合 sRGB 编码的文件，可用 sRGB 电光转换的逆函数近似回到线性 RGB。但 webcam 视频链可包含额外色调、限定范围 YUV、HDR 或制造商特定处理。因此“inverse-sRGB”只能显示为**近似选项**，不能取代实测相机响应函数。

## 7. 通道标定与选择

对每个 R/G/B 通道分别记录：

- 暗场均值和标准差；
- 环境背景；
- 峰值、饱和像素比例、最长平顶；
- 峰谷对比度和 SNR；
- 线性范围（如已标定）；
- 激光波长下的相对灵敏度（如已独立标定）。

选择通道时首先排除饱和，再在未饱和通道中选信噪比和峰谷对比度较好者。标准灰度是面向视觉/显示的加权，不保证在窄带激光下具有最佳 SNR。

使用非主颜色通道来回避饱和会带来色彩串扰、去马赛克和信噪比问题。可以用于定位试验，但不应被解释为主通道真实峰顶的定量恢复。

## 8. 饱和与有效动态范围

### 8.1 饱和不只是 DN = 255

对 8-bit Canvas，接近 255 的大量像素是明显警号，但实际视频链还可能：

- 使用 limited-range YUV，在转换前就已剪切；
- 通过色调曲线把高光压缩为未达 255 的平台；
- 在单个 Bayer 通道上先饱和，后续去马赛克才产生 RGB；
- 产生 blooming、锐化光晕或局部 HDR 假影。

因此应同时检查：

- 每个 RGB 通道的高码值比例；
- 直方图高端堆积；
- 连续平顶长度；
- 峰顶斜率长时间接近零；
- 相邻像素/通道的异常外溢。

`>=250/255` 可作为 8-bit 数据的强剪切警告起点，但不是完整的饱和定义，阈值必须能按设备验证。

### 8.2 饱和后的处理

- 峰高：无效；
- FWHM：无效；
- 完整强度模型拟合：不可作为高可信结果；
- 亚像素峰顶拟合：无效；
- 未受影响的暗纹/侧峰位置：经原图复核后可作降级位置法。

有价值的解决方式是重新采集，降低曝光/增益/激光功率或添加合适 ND，而不是用插值画出一个看似完整的山峰。

## 9. 平场校正（高级路线图）

平场用于修正位置相关的增益，包括镜头暗角、像素响应非均匀性、屏幕缓慢反射不均等。设线性化的暗场为 \(D(x,y)\)，线性化平场为 \(F(x,y)\)，则归一化增益图为

\[
G(x,y)=
\frac{F(x,y)-D(x,y)}
{\left\langle F-D\right\rangle}.
\]

目标激光信号 \(S=M-M_{\rm off}\) 的平场修正为

\[
S_{\rm corr}(x,y)=\frac{S(x,y)}{G(x,y)}.
\]

必要条件：

- 图像已在近似线性域；
- 平场光源稳定、在 ROI 上可验证地均匀；
- 平场与实验使用相同的镜头、焦距、对焦、分辨率和相机设置；
- 在需要较严格的窄带激光测量时，平场的光谱条件与实验波长匹配或已证明可转移；
- \(F-D\) 远高于噪声底且未饱和；
- 屏幕上没有会被当成增益校正的尖锐污点/阴影。

平场不是“取一张白纸照片就除一下”。没有可验证均匀光源时，不做平场比应用错误平场更容易解释。

## 10. 相对强度的归一化

在得到背景修正剖面 \(S_i\) 后，常用归一化是

\[
R_i=\frac{S_i}{\max_j S_j}.
\]

但如果最大峰饱和，这种归一化没有可信物理意义。可替代地用未饱和参考峰、一组有效点的积分或外部参考作归一化，但必须把分母和有效范围写入元数据。

不同日期、不同相机或不同曝光下的 a.u. 数值不能默认相互可比。若只关心波长，使用峰/谷位置而不必过度解读归一化峰高。

## 11. 绝对辐射定标为什么更难（路线图）

摄像头对光屏成像时直接观测的是屏幕朝镜头方向的辐亮度，而实验物理常关心到达光屏的辐照度。两者之间还有光屏的双向反射分布（BRDF）、入射/观察角、波长和偏振依赖性。

要输出可追溯 W/m² 或 W·m⁻²·sr⁻¹，至少需要：

1. 已知波长/线宽下的可溯源辐射参考；
2. 当前相机、镜头、焦距、光圈、曝光、增益、温度和通道的 DN-to-radiance 响应；
3. 黑电平、响应线性、读出噪声、平场、光谱响应和饱和边界；
4. 相机的有效立体角/成像几何；
5. 若要从辐亮度推回屏面辐照度，还需光屏的波长和角度相关反射特性；
6. 完整不确定度预算和校准有效期。

照度计不能直接完成这条标定链。lux 是按人眼明视觉函数加权的光度学量，而 RGB/DN 是设备特定响应；NIST 的[辐射度学/光度学概述](https://www.nist.gov/publications/radiometry-and-photometry-review-vision-optics)详述了这些量的区别。对理想单色光，lux 与辐照度之间在已知波长和光谱纯度时可以建立理论换算，但这仍不会自动校准光屏反射、镜头和相机响应。

所以，除非用户导入了在当前整套条件下取得的有效定标文件，界面和报告始终应使用 DN 或 a.u.。

## 12. 标定文件应保存的内容

每个标定记录应有唯一 ID，并至少包含：

- 创建时间、操作者、软件版本/commit；
- 相机设备标识、镜头和连接路径；
- 原始分辨率、裁剪、帧率、旋转、变焦和防抖状态；
- 所有可读取的实际相机 settings；
- 颜色通道和图像编码路径；
- 空间标定点的原始像素坐标和真实坐标；
- 两点比例或 homography/畸变参数；
- 重投影/验证误差和不确定度；
- 暗场、背景、平场和响应函数的原始数据或可追溯链接；
- 有效信号范围、饱和阈值和残差；
- 激光波长/平场光谱/温度等适用条件；
- 有效期、重标触发条件和已知限制。

标定文件只保存最终一个 `mm/pixel` 数字是不充分的，因为无法重新计算不确定度或发现点选择错误。

## 13. 必须重新标定的情况

任一项发生时，至少重做空间标定；如果涉及响应链，也重做背景/线性/平场校正：

- 更换相机、镜头、转接器或摄影应用；
- 更改分辨率、帧率、旋转、裁剪、变焦、防抖或对焦；
- 移动相机、光屏或标定尺；
- 改变曝光、增益、白平衡、HDR 或颜色处理；
- 操作系统/浏览器/驱动更新后发现实际设置或图像管线改变；
- 温度变化超出定标验证范围，且暗信号/响应对温度敏感；
- 更换激光波长，且要使用平场或辐射定标；
- 验证点的误差超出项目预先设定的限值。

- [ ] 使用原始像素坐标
- [ ] 标定方向与剖面方向一致

- [ ] \(a\) 或 \(d\) 定义和公差明确

- [ ] 变焦/分辨率/相机位置自标定后未变

### 相对峰高实验

- [ ] 上述位置检查全部通过
- [ ] 曝光/增益/白平衡/对焦实际稳定
- [ ] 暗场和 laser-off 背景与实验帧设置相同
- [ ] 选中通道和主通道都未饱和
- [ ] 响应线性已验证，或结果明确标为 DN 域
- [ ] 如使用平场，其光谱、几何和相机条件有效
- [ ] 归一化分母未饱和且已记录

### 绝对输出

- [ ] 存在针对当前全链路、波长和几何的可溯源定标
- [ ] 辐亮度与屏面辐照度之间的反射模型有效
- [ ] 不确定度预算完整
- [ ] 定标未过期，验证点在限值内

如果最后一组未全部通过，不得显示 lux 或 W/m²。
